# 机器狗跳舞系统技术架构文档

## 系统架构概览

### 分层架构设计

```
┌─────────────────────────────────────────────────────────┐
│                  用户界面层 (UI Layer)                    │
├─────────────────────────────────────────────────────────┤
│    跳舞编排界面  │  多机控制台  │  实时监控  │  动作预览   │
├─────────────────────────────────────────────────────────┤
│                 应用服务层 (Service Layer)                │
├─────────────────────────────────────────────────────────┤
│ 编排服务 │ 同步服务 │ 音频服务 │ 动作库服务 │ 网络服务    │
├─────────────────────────────────────────────────────────┤
│                 核心业务层 (Core Layer)                   │
├─────────────────────────────────────────────────────────┤
│ 动作引擎 │ 时间轴  │ 插值器  │ 同步器    │ 编队管理      │
├─────────────────────────────────────────────────────────┤
│                 数据访问层 (Data Layer)                   │
├─────────────────────────────────────────────────────────┤
│ 动作文件 │ 配置文件 │ 音乐文件 │ 日志文件 │ 缓存数据     │
├─────────────────────────────────────────────────────────┤
│                 硬件抽象层 (HAL)                          │
└─────────────────────────────────────────────────────────┘
│  机器狗A  │  机器狗B  │  机器狗C  │  音响设备  │  输入设备   │
```

## 核心组件设计

### 1. 动作执行引擎 (ActionEngine)
- **设计目标**: 高精度姿态控制、平滑动作过渡、实时动作调整、多机器狗并发执行
- **核心类**: `ActionEngine`, `PoseInterpolator`, `MotionExecutor`, `Timeline`, `SyncManager`
- **插值算法**: 线性插值、贝塞尔曲线、样条插值、物理模拟

### 2. 时间轴管理系统 (Timeline)
- **数据结构**: 多轨道字典、当前时间、播放状态、循环模式
- **轨道类型**: 主体轨道、头部轨道、尾部轨道、腿部轨道、音频轨道

### 3. 多机器狗同步系统
- **网络架构**: 指挥中心 (Master Node) 与机器狗节点群组通过 WebSocket 连接
- **同步协议**: 时间同步机制、延迟补偿、编队管理

### 4. 音乐同步系统
- **音频分析**: 节拍检测、音调变化、能量变化
- **节拍同步**: 将动作同步到音乐节拍，支持同步容差

## 用户界面设计

### 1. 主界面布局
- **组件**: 动作库、3D预览窗口、时间轴编辑器、多机控制面板、状态监控

### 2. 时间轴编辑器
- **功能**: 拖拽式动作编排、多轨道并行编辑、实时预览播放、缩放和导航、关键帧精确编辑

### 3. 3D预览系统
- **功能**: 加载机器狗3D模型、更新姿态、渲染当前帧

## 数据模型设计

### 1. 核心数据结构
- **类**: `Pose`, `Keyframe`, `Action`, `ActionSequence`

### 2. 配置管理
- **功能**: 加载配置文件、获取最大机器狗数量、同步容差、默认插值类型

## 开发工具和环境

### 1. 开发环境配置
- **Python依赖**: `numpy`, `scipy`, `asyncio`, `PyQt5`, `librosa`, `open3d`, `websockets`, `pyyaml`

### 2. 项目结构建议
- **模块**: `core/`, `choreography/`, `multi_dog/`, `audio/`, `ui/`, `data/`, `tests/`, `docs/`

## 性能优化策略

### 1. 实时性能优化
- **指标**: 控制循环延迟 <10ms, 同步精度 ±20ms, 帧率 60FPS (预览), 20Hz (控制)
- **技术**: 异步I/O, 多线程并行处理, 缓存预计算结果, GPU加速计算

### 2. 内存管理
- **功能**: 动作缓存、姿态缓冲区

### 3. 网络优化
- **策略**: 命令压缩和批处理、预测性发送和补偿、自适应品质调整、错误检测和恢复

## 安全和容错设计

### 1. 安全机制
- **功能**: 姿态验证、紧急停止

### 2. 容错处理
- **策略**: 网络断线自动重连、命令失败重试机制、状态不一致自动同步、异常情况安全降级
