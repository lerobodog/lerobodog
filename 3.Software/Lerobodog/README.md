# Lerobodog 软件资源

本目录包含 Lerobodog 相关的软件源码、工具和说明文档。

## 文件说明

- `src/`: 软件源码
- `docs/`: 使用和开发文档
- `tools/`: 相关工具

## 使用说明

1. 克隆软件仓库到本地：`git clone <软件仓库地址>`
2. 安装依赖：`pip install -r requirements.txt`
3. 运行主程序：`python3 main.py`

## 开发

- 使用 `ros2` 进行机器人控制开发。
- 参考 `docs/` 目录下的官方文档进行开发。
