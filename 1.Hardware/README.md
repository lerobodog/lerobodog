# 硬件资源

本目录包含 Lerobodog 相关的硬件设计文件、图纸和说明文档。

## 子目录说明

- `Alphababy/`: Alphababy 机器人硬件设计文件
- `Lerobot/`: Lerobot 机器人硬件设计文件
- `Power Adaper/`: 电源适配器相关设计
- `RDK x5/`: RDK x5 硬件资料

## 使用说明

1. 下载硬件设计文件（如 `.stl` 或 `.step` 文件）用于 3D 打印或加工。
2. 参考 `Bom.xlsx` 文件准备所需物料。
3. 组装时请遵循 `5.Docs/组装过程/` 中的指南。

## 贡献

欢迎提交硬件改进建议或设计优化。请确保提交的文件格式正确，并附上说明文档。
