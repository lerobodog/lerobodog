# 电源适配器资源

本目录包含 Lerobodog 相关的电源适配器设计文件和说明文档。

## 文件说明

- `Schematics/`: 电路原理图和 PCB 设计文件
- `BOM/`: 物料清单（Bill of Materials）
- `Test_Reports/`: 电源适配器测试报告

## 使用说明

1. 参考 `Schematics/` 目录下的电路设计文件。
2. 使用 `BOM/` 目录下的物料清单准备所需组件。
3. 测试时请参考 `Test_Reports/` 中的测试结果。

## 贡献

欢迎提交电源适配器改进建议或设计优化。请确保提交的文件格式正确，并附上说明文档。
