# Lerobot 硬件资源

本目录包含 Lerobot 机器人的硬件设计文件、图纸和说明文档。

## 文件说明

- `3D_Models/`: 3D 打印模型文件（`.stl` 或 `.step` 格式）
- `Schematics/`: 电路原理图和 PCB 设计文件
- `BOM/`: 物料清单（Bill of Materials）

## 使用说明

1. 下载 3D 模型文件用于打印或加工。
2. 参考 `BOM/` 目录下的物料清单准备所需组件。
3. 组装时请遵循 `5.Docs/组装过程/` 中的指南。

## 贡献

欢迎提交硬件改进建议或设计优化。请确保提交的文件格式正确，并附上说明文档。
