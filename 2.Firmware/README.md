# 固件资源

本目录包含 Lerobodog 相关的固件源码和说明文档。

## 子目录说明

- `Alphababy/`: Alphababy 机器人固件源码
- `Lerobot/`: Lerobot 机器人固件源码
- `RDK x5/`: RDK x5 固件源码

## 使用说明

1. 克隆固件仓库到本地：`git clone <固件仓库地址>`
2. 根据硬件版本选择对应的固件分支。
3. 编译并烧录固件到目标设备。

## 调试

- 使用串口工具（如 `minicom`）查看设备日志。
- 参考 `official/` 目录下的官方文档进行调试。

欢迎提交固件改进或 Bug 修复。请确保代码符合编码规范，并附上测试结果。
