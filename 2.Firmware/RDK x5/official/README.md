# RDK x5 官方固件

本目录包含 RDK x5 的官方固件源码和说明文档。

## 文件说明

- `src/`: 固件源码
- `docs/`: 固件使用和开发文档
- `tools/`: 相关工具（如烧录工具）

## 使用说明

1. 克隆固件仓库到本地：`git clone <固件仓库地址>`
2. 编译固件：`make build`
3. 烧录固件到目标设备：`make flash`

## 调试

- 使用串口工具（如 `minicom`）查看设备日志。
- 参考 `docs/` 目录下的文档进行调试。
