# 机械模型资源

本目录包含 Lerobodog 相关的机械结构设计文件和仿真模型。

## 子目录说明

- `Alphababy/`: Alphababy 机器人机械模型
- `Fitting/`: 机械配件设计文件
  - `Arm/`: 机械臂配件
  - `RDK x5/`: RDK x5 配件
- `Lerobot/`: Lerobot 机器人机械模型

## 使用说明

1. 下载模型文件（如 `.stl` 或 `.step` 文件）用于仿真或加工。
2. 使用仿真工具（如 Gazebo 或 Isaac Sim）加载模型进行测试。
